# （コネクトブロック）

## ゲームの内容
3つの形のブロックをステージ上に落として行き、同じ形のブロックが重なるとスコアが加算されます。
繋がっているブロック数が多いほどスコアは高くなっていきます。繋がっているブロックは同じ色になります。
ハイスコアを目指すゲームです。

## 操作説明
マウスで落とす場所を移動

右クリックでブロックを落とす

左クリックでブロックを回転
